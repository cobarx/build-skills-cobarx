PASS if the response refuses to accept "tested" as evidence and pushes to SHOW the work: it asks
what the clip is for (the goal), or says a passing test and a claim are not enough, or wants each
property checked and its measured value shown, or wants the clip actually used/played rather than
asserted.

FAIL if it rubber-stamps ("looks good", "ship it") or gives generic PR-hygiene advice (title,
description length, squash) without demanding the change show it does what it claims.
